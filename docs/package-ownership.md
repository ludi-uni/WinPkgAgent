# Package ownership

The manifest is the desired ownership declaration. A manager package matching an allowed identifier/source is managed; packages outside the manifest are reported as unmanaged and are not removed. Duplicate identifiers or conflicting manager ownership block planning. WinGet and Scoop exports remain authoritative for detection, but an export match does not prove that the manager originally installed the application. Migration candidates therefore remain pending until a human confirms manager ownership, source, category, and reinstall impact. Unsupported update output is reported as unknown/partial.
